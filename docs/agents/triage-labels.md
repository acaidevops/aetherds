# Triage labels

| Canonical role | GitHub label | Meaning |
|---|---|---|
| `needs-triage` | `needs-triage` | Maintainer evaluation required |
| `needs-info` | `needs-info` | Waiting for reporter or stakeholder information |
| `ready-for-agent` | `ready-for-agent` | Fully specified and safe for an AFK agent |
| `ready-for-human` | `ready-for-human` | Requires a human-only decision or action |
| `wontfix` | `wontfix` | Will not be actioned |

Use exactly one workflow-state label when an issue is triaged. Domain, type,
priority, and epic labels are independent of this workflow state.
